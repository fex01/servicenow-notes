# Readable, size-optimized PDFs

- Create a PDF only when requested or needed for the user's task. Obtain content through authorized access; preserve source order and retain captions, code, images and links where available. Do not include browser credentials, cookies, tokens or unrelated account data.
- Place the final optimized PDF in `course-ebooks/` at the repository root by default, using a descriptive course and edition filename; honor an explicitly requested destination. Link the final PDF from the relevant notes. Use ignored `output/` or a temporary directory for intermediate artifacts.
- Keep the original or a verified lossless working copy. Run `python scripts/pdf_optimize.py INPUT OUTPUT --mode lossless` for object and stream compression. Where meaningful, also try `--mode balanced` for lossless work plus high-quality JPEG re-encoding of eligible RGB images; no downsampling. Use the smaller copy only after checks. Image re-encoding is lossy. Eligible RGB screenshots and images with soft masks can be re-encoded without resizing; the original soft mask is retained. Unsupported image formats remain unchanged; record skipped images and limitations. Check actual visual quality and size, not just assumed savings.
- The helper compares per-page extracted text, page count, page boxes, metadata, nested outline summaries and supported annotation details, and reports image changes. It supports pypdf 6.x and requires Pillow in balanced mode. These checks do not guarantee all link destinations, annotations, transparency, tags, form fields or accessibility survive; inspect such features explicitly when present. Do not use the lossy option on PDFs with forms, signatures, tagged accessibility requirements, or other sensitive features without selecting and validating an appropriate specialized workflow. A digital signature may be invalidated by any rewrite.
- Render and visually inspect representative pages from the original and candidate: small text, screenshot-heavy pages, diagrams, code, transparency, page edges, and beginning/end. Select samples from the actual document; use more when risk warrants. Compare original and candidate at practical reading zoom. If image readability, layout or important features are unverified, deliver the safer verified copy and identify the limitation.
- Report input/output size, whether compression was lossy, checks performed and any limits. Never call lossy images unchanged just because text extraction matches. Keep all source material and credentials out of logs.
